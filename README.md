# フードサプライズ｜介護施設・保育園むけ 商談スライド 一式

2画面方式（商談ビュー＋顧客画面）のWebスライドです。全19枚。

## 中身

| ファイル | 用途 |
|---|---|
| `index.html` | **完成品**。これ1つで動く（CSS・JS・カバー画像すべて内蔵）。デプロイ／商談で使うのはこれ。 |
| `介護保育園_構成_台本.md` | 各スライドのテキストと台本（スピーカーノート）の編集用リファレンス。 |
| `src/webgen2.js` | スライド生成スクリプト。内容を編集して `index.html` を作り直すときに使う。 |
| `src/css.txt` | スタイル（`webgen2.js` が読み込む）。 |
| `src/app.txt` | 画面制御・2画面同期のランタイムJS（`webgen2.js` が読み込む）。 |
| `src/hero_b64.txt` | 表紙のカバー画像（base64）。 |

## すぐ使う（商談・デプロイ）

`index.html` を開くと **商談ビュー（presenter）** が出ます。
1. 右上「🖥 顧客画面を別タブで開く」→ 別タブに **顧客画面** が開く。
2. Zoom等では **顧客画面タブだけを画面共有**。
3. presenter側でスライド一覧クリック／分岐早見表クリックすると、顧客画面が連動します（同一オリジンで動作）。

顧客画面は単体でも操作可：`←→` で送り、メニューの施設カードで分岐、区間末の「共通プランへ」で合流。

### Vercel等へのデプロイ
`index.html` をそのまま配置すればOK（`public/index.html` など）。2画面同期は同一オリジンで動きます。ローカル確認は `index.html` をブラウザで直接開くだけでも可。

## 内容を編集して作り直す

`src/webgen2.js` の上部にある各テンプレート関数（`cover` `concept` `pricing` `benef` など）や `TG`（施設ごとの色）、`NOTE`（台本）、`BRANCH`／`QUICK`（分岐）を編集し、`src/` 内で実行：

```bash
cd src
node webgen2.js   # → /mnt/... ではなく、出力先パスは環境に合わせて変更
```

※ `webgen2.js` 末尾の `fs.writeFileSync('/mnt/user-data/outputs/index.html', ...)` の出力先を、自分の環境の任意パスに書き換えてください。`css.txt`／`app.txt`／`hero_b64.txt` は同じ `src/` 直下に置いたまま実行します。
