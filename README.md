# Food Surprise｜介護施設・保育園向け 台本操作型Webスライド

Aidech_present形式をベースにした、営業商談用Webスライドです。

## 特徴

- 発表者ビュー：台本・質問・押さえるポイントを表示
- 顧客表示：スライドのみ表示
- 2画面同期
- `index.html` 単体で動作する self-contained 静的サイト
- Vercelで静的デプロイ可能

## 使い方

1. デプロイURLを開く
2. 右上の「顧客表示を開く」を押す
3. Web会議では、開いた顧客表示ウィンドウだけを共有
4. 手元の発表者ビューで台本を見ながら進行

## 操作

- `→` / `Space`：次へ
- `←`：前へ
- `1`〜`9`：スライド番号へ
- `0`：10枚目へ
- `F`：全画面

## 今回の提案方針

分岐型・万能型ではなく、介護施設・保育園に絞った単一路線プレゼン。

- 介護施設：買い物に行きづらい入居者様へ、季節の山形フルーツを届ける
- 保育園：園行事・食育・保護者向け案内として、季節の食体験を届ける

## 重要ルール

- 金額表記は 3,500円・6,000円に統一
- 3,000円表記は使わない
- クール便送料・支払い方法は断定しない
- 少数発注・個人単位・サンプル配布は「相談可能」として扱う
- 条件が固まり切っていなくても、興味があれば担当へトスアップする
